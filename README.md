📄 مصمم السيرة الذاتية المتقدم

نظرة عامة

تطبيق ويب متكامل لتصميم السيرة الذاتية بشكل احترافي مع إمكانيات متقدمة مثل التعديل المباشر، التحكم بالألوان والخطوط، معاينة فورية، وخيارات متعددة للتحميل والمشاركة.

✨ المميزات

🎨 التصميمات

· 4 تصاميم مختلفة: كلاسيكي، الصورة بالأعلى، جانبي، عصري
· 6 ألوان أساسية قابلة للتخصيص
· خطوط عربية وإنجليزية متنوعة (تاجوال، المسيري، تشانغا، إنتر، SF Pro)

🖼️ الصورة الشخصية

· رفع صورة من الجهاز
· تحميل صورة من رابط ويب
· التحكم بحجم الصورة (أحجام مسبقة أو مخصصة)
· إمكانية تغيير شكل الصورة (دائرة/مستطيل)
· تغيير لون إطار الصورة

✏️ التعديل

· وضع التعديل المباشر (Click to Edit)
· إضافة وحذف وتعديل الأقسام
· محرر نصوص متكامل (عريض، مائل، تحته خط)
· التحكم بحجم ولون النصوص
· إدارة الخبرات والمهارات والتعليم بسهولة

📥 التحميل والمشاركة

· تحميل بصيغة PNG بجودة (4K، عالية، عادية)
· تحميل بصيغة PDF للطباعة والتقديم الرسمي
· مشاركة عبر: فيسبوك، تويتر، لينكد إن، واتساب
· نسخ الرابط للمشاركة

🚀 التقنيات المستخدمة

· HTML5 - هيكل التطبيق
· CSS3 - التصميم والتنسيق مع متغيرات CSS
· JavaScript (ES6) - المنطق والتفاعل
· Font Awesome 6 - الأيقونات
· Google Fonts - الخطوط العربية والإنجليزية
· html2canvas - تحويل السيرة إلى صورة
· Web APIs (Clipboard, FileReader, execCommand)

📦 التثبيت والتشغيل

المتطلبات المسبقة

· متصفح ويب حديث (Chrome, Firefox, Edge, Safari)
· اتصال بالإنترنت (لتحميل الخطوط والمكتبات)

طريقة التشغيل

1. طريقة سريعة: قم بفتح ملف index.html مباشرة في المتصفح
2. طريقة السيرفر المحلي (اختياري):

```bash
# باستخدام Python
python -m http.server 8000

# باستخدام Node.js (http-server)
npx http-server

# باستخدام Live Server في VS Code
# اضغط على Go Live في شريط الحالة
```

📂 هيكل الملفات

```
├── index.html              # التطبيق الرئيسي (ملف واحد متكامل)
├── README.md              # هذا الملف
└── (ملفات إضافية)
    ├── fonts/             # خطوط محلية (اختياري)
    └── images/            # صور افتراضية (اختياري)
```

ملاحظة: التطبيق يعمل كملف واحد متكامل (Single Page Application) حيث يحتوي على HTML، CSS، وJavaScript في ملف واحد.

🎯 كيفية الاستخدام

الخطوات الأساسية

1. اختر التصميم المناسب من شريط الأدوات
2. أضف صورتك الشخصية (رفع أو رابط)
3. أدخل المعلومات الشخصية (الاسم، المسمى الوظيفي، النبذة)
4. أضف الخبرات والمهارات والتعليم
5. خصص الألوان والخطوط حسب رغبتك
6. قم بتحميل أو مشاركة سيرتك الذاتية

واجهة المستخدم

· شريط الأدوات (يمين): يحتوي على جميع أدوات التحكم والتخصيص
· منطقة المعاينة (يسار): تعرض السيرة الذاتية بشكل فوري
· أزرار التحكم العلوية: إضافة قسم، وضع التعديل، المشاركة

🔧 حل المشكلات الشائعة

❌ الصورة لا تظهر

· تأكد من صحة الرابط (يجب أن ينتهي بـ .jpg, .png, .gif)
· تأكد من أن الصورة متاحة للعامة
· جرب رفع الصورة من الجهاز بدلاً من الرابط

❌ التحميل لا يعمل

· تأكد من تفعيل JavaScript في المتصفح
· جرب استخدام متصفح آخر
· تحقق من اتصال الإنترنت (لتحميل html2canvas)

❌ الخطوط لا تظهر

· تأكد من اتصال الإنترنت (لتحميل Google Fonts)
· جرب تحديث الصفحة (Ctrl+F5)
